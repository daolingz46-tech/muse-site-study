# 成品账号卡密邮件交付

工作台在核实收款后，为成品账号订单显示绿色“发送邮件”。店主从 1688 邮件复制卡密，粘贴到该订单；收件人固定为买家下单时填写的邮箱。发送成功后订单标记已交付，操作仍保留紫色“再次发送”。卡密不保存在订单数据库；再次发送时需要重新粘贴。

## 更新已部署的 Google 脚本

新增图片、视频邮件附件需要更新原 Google Apps Script 部署，保留原网址和 `BRIDGE_TOKEN`。更新前，卡密和默认教程仍可发信；工作台的“添加附件”暂时不可用。

1. 打开原来的 Apps Script 项目，把 [`email-notifier-gas/Code.gs`](../email-notifier-gas/Code.gs) 全部内容复制到编辑器，覆盖旧代码并保存。
2. 点击右上角 **部署 → 管理部署**，找到当前“网页应用”部署，点击铅笔 **编辑**。
3. 在“版本”中选 **新版本**，点击 **部署**。不要创建另一个网址，也不要修改“执行身份”和访问权限。
4. 刷新 [店主工作台](https://musetoken.store/admin/)。当“添加附件”可以点击时即可使用。

Google 的[部署说明](https://developers.google.com/apps-script/concepts/deployments)指出，更新现有网页应用要新建版本并编辑原部署；这样 URL 保持不变。

## 维护图文教程

工作台已保存成品账号教程的文字步骤和图片。在“成品账号图文教程”区可继续编辑。发送邮件时“附带默认教程”默认勾选；某笔订单无需教程时取消勾选。教程图片以不可猜测的网址保存在订单服务，邮件客户端需要允许显示图片；文字内容同时提供纯文本版本。

## 订单专属附件

发送邮件窗口点“添加附件”可上传 PNG、JPG、WebP、GIF、MP4、MOV 或 WebM。每笔订单最多保存 4 个附件、合计 20 MB，单个不超过 15 MB。附件会作为真正的邮件文件发送；Gmail 的单封邮件附件上限为 25 MB。再次发送时可重新选择已保存的附件，也可以删除并换上新文件。附件存在订单数据库里，长期使用大视频会占用数据库空间。

## 发卡步骤

1. 客户下单后，先核对微信或支付宝到账，再点击“核实收款”。
2. 从 1688 收到的邮件里复制卡密。
3. 在对应成品账号订单点“发送邮件”，核对买家的收件邮箱，粘贴卡密；默认教程已经勾选，需要时再添加专属附件。
4. 发送成功后订单变为“已交付 · 可售后”，按钮变为“再次发送”。再次发送时重新粘贴卡密。如果显示发送失败，先查看 Gmail 发件箱，再决定是否重试，避免重复发卡。

Token 充值订单没有买家邮箱，仍按邀请码充值流程处理。
