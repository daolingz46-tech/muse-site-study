# 成品账号卡密邮件交付

工作台在核实收款后，为成品账号订单显示“发送邮件”。店主从 1688 邮件复制卡密，粘贴到该订单；收件人固定为买家下单时填写的邮箱。发送成功后订单自动完成。卡密不保存在订单数据库；数据库只记录邮件交付时间。

## 更新已部署的 Google 脚本

现有 Google Apps Script 版本只允许发给店主，因此需要更新原部署，保留原网址和 `BRIDGE_TOKEN`。

1. 打开原来的 Apps Script 项目，把 [`email-notifier-gas/Code.gs`](../email-notifier-gas/Code.gs) 全部内容复制到编辑器，覆盖旧代码并保存。
2. 点击右上角 **部署 → 管理部署**，找到当前“网页应用”部署，点击铅笔 **编辑**。
3. 在“版本”中选 **新版本**，点击 **部署**。不要创建另一个网址，也不要修改“执行身份”和访问权限。
4. 刷新 [店主工作台](https://musetoken.store/admin/)。当“买家卡密邮件还需更新 Google 脚本”的提示消失时，即可使用发送邮件按钮。

Google 的[部署说明](https://developers.google.com/apps-script/concepts/deployments)指出，更新现有网页应用要新建版本并编辑原部署；这样 URL 保持不变。

## 维护图文教程

在工作台的“成品账号图文教程”区编辑标题、文字段落和图片。支持 PNG、JPG、WebP 图片；大图会在浏览器中压缩，单张最多 700 KB。点击“保存教程”后，之后的卡密邮件会自动附上当前版本的图文。教程图片以不可猜测的网址保存在订单服务，邮件客户端需要允许显示图片；文字内容同时提供纯文本版本。

## 发卡步骤

1. 客户下单后，先核对微信或支付宝到账，再点击“核实收款”。
2. 从 1688 收到的邮件里复制卡密。
3. 在对应成品账号订单点“发送邮件”，核对买家的收件邮箱，粘贴卡密并确认。
4. 发送成功后订单变为“已完成”。如果显示发送失败，先查看 Gmail 发件箱，再决定是否重试，避免重复发卡。

Token 充值订单没有买家邮箱，仍按邀请码充值流程处理。
