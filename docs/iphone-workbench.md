# iPhone 工作台提醒

## 设置

1. 在 iPhone 的 Safari 打开 `https://musetoken.store/admin/`，登录工作台。
2. 点 Safari 的“分享”按钮，选择“添加到主屏幕”。从主屏幕的 Muse 工作台图标重新打开。
3. 点“开启手机推送”，在系统弹窗中允许通知。再点“测试手机推送”确认能收到。
4. 若希望工作台显示在前台时发出叮声，再点“开启订单叮声”试听。网页提示音需要每次重新打开页面后点一次按钮，以符合浏览器播放限制。

新订单和买家第一次提交付款反馈都会发送系统推送。锁屏或关闭工作台后，iOS 不会保持网页运行；提醒由系统推送送达。锁屏提示音、专注模式和静音开关由 iPhone 系统控制，网页不能指定锁屏提示音。请在“设置 → 通知 → Muse 工作台”检查通知权限。

手机推送需要 iOS 16.4 或更新版本以及可访问该网站的网络。微信内置浏览器不提供本网站的主屏幕网页推送入口，请使用 Safari 安装。打开网页时的订单列表仍每 5 秒刷新一次；后台时不依赖网页轮询。
