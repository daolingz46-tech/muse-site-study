# 微信店主工作台

使用微信开发者工具导入本目录，AppID 已配置。微信公众平台配置 request 合法域名为 https://api.musetoken.store，按微信后台实际要求完成域名及备案校验。登录使用现有工作台密码，会话只保存在内存中。

通过开发管理的体验版和体验成员限制使用，不提交公开发布；体验版规则和期限以微信后台当前提示为准。手机前台每 10 秒检查最近 50 笔订单，点击开启语音后可播放本地提示音；后台、锁屏无法保证播放。微信订阅消息需要额外的模板、用户授权及服务端配置，本项目未假装已实现后台推送。

核实收款依旧由店主人工核对；发货时沿用服务端库存优先和重复采购防护。网络中断时先核查订单状态。
